# cpe-one-star

This repository contains Python solutions for the CPE one-star programming problem set. It is intended as a personal practice archive for strengthening basic algorithmic thinking, UVa-style input/output handling, and common competitive programming patterns.

## Reference

The problem list follows the CPE one-star required problem collection:

- https://blog.iddle.dev/public/2023/05/01/CPE-49%E9%A1%8C%E5%BF%85%E8%80%83%E4%B8%80%E6%98%9F%E9%A1%8C/

## Repository Structure

Each Python file is a standalone solution. The file names are organized by problem index.

```text
cpe-one-star/
├── 1-1.py
├── 1-2.py
├── 1-3.py
├── ...
├── 1-49.py
└── README.md
```

Some problems may include alternative or experimental versions, such as BFS-only or revised implementations.

## Requirements

- Python 3.x

Most solutions use only the Python standard library, so no additional packages are required.

## Usage

Clone the repository:

```bash
git clone https://github.com/Ian684/cpe-one-star.git
cd cpe-one-star
```

Run a solution directly:

```bash
python3 1-1.py
```

Or run it with input redirection:

```bash
python3 1-1.py < input.txt
```

## Study Focus

This repository is useful for practicing fundamental competitive programming topics, including:

- Basic input and output
- Loops and conditional logic
- Arrays and lists
- String processing
- Sorting
- Simulation
- Number theory basics
- Simple graph traversal
- Basic dynamic programming
