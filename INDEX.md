# CPE one-star index

The numbered files are standalone solutions for the one-star practice set.

## Problem files

- `1-1.py` through `1-49.py`
- `1-37(bfs-only-graph).py` — alternate graph implementation
- `10323.py`, `10943.py`, `11743.py` — additional UVa-style practice

## Suggested workflow

1. Read the original CPE/UVa statement and identify the input termination
   rule.
2. Solve the problem independently before opening the matching file.
3. Test normal, boundary, and repeated-case input.
4. Record the algorithm and complexity when reviewing a solution.

Run a solution with:

```bash
python3 1-1.py < input.txt
```

The programs intentionally remain standalone so each can be copied into an
online judge without package setup.
